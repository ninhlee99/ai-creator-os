MiuNova

MiuNova is a personal, self-hosted application for its operator. It can run on the operator's computer or VPS and connect TikTok accounts the operator owns or is authorized to manage. It is not offered to the public.

How it works

  1. The creator signs in with TikTok (Login Kit) and grants the user.info.basic and video.upload scopes.
  2. The operator authorizes MiuNova with TikTok. For VPS use, the registered redirect URI can point to the MiuNova HTTPS callback. The static relay page is a manual copy-and-paste fallback.
  3. Draft upload is the default. Direct Post requires the relevant TikTok product, scope and eligibility; it is not assumed to be available.
  4. Videos and required metadata are sent to TikTok when the operator starts an upload or publish action. Drafts are reviewed in TikTok before publication.
