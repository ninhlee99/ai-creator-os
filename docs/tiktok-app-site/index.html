MiuNova

MiuNova is a personal, self-hosted application for its operator. It can run on the operator's computer or VPS and connect TikTok accounts the operator owns or is authorized to manage. It is not offered to the public.

How it works

  1. The creator signs in with TikTok (Login Kit) and grants the user.info.basic and video.upload scopes.
  2. The operator authorizes MiuNova with TikTok Login Kit for Desktop. The app uses PKCE and a loopback callback; the default URI is http://127.0.0.1:8080/publishers/tiktok/callback, which must be registered in TikTok Developer Portal.
  3. This build uploads drafts only. Direct Post is disabled until eligibility is verified and per-post consent controls exist.
  4. Videos and required metadata are sent to TikTok when the operator starts a draft upload. Drafts are reviewed in TikTok before publication.
