## 3. Upload and publishing
The application sends video and associated metadata to TikTok when its operator starts a draft upload. Drafts must be reviewed and published in TikTok. Direct Post is not supported by this build.

## 4. Revoking access
You can revoke TikTok access under Settings and privacy → Security → Manage app permissions. The instance owner can remove the account's token file from MiuNova's `<dataDir>/tokens` directory on the host. If the instance makes backups, matching backup copies must be handled separately.
