# TikTok Shop Open Platform APIs — Research Brief (Vietnam, Oct 2026)

## 1. Affiliate APIs (TikTok Shop Open Platform — partner.tiktokshop.com)

**Registration & auth (applies to all TikTok Shop APIs):**
- Register an app at **partner.tiktokshop.com** as an **Affiliate** app developer type. Auth is OAuth 2.0 (app key + app secret; access token obtained via seller/creator authorization through Seller Center / TikTok app). Requests are HMAC-signed.
- **App review is mandatory before production use.** Sandbox testing is available during development; production credentials require submitting use-case documentation + demo. (Timeline not officially published; third-party builders report days-to-weeks.)
- TikTok Shop developer docs live at partner.tiktokshop.com/docv2 (login/JS-gated; not all pages are publicly fetchable).

**Affiliate Creator APIs — authorized by the CREATOR's TikTok account (this is the user's lane: creator doing affiliate).** From the TikTok Shop API surface (corroborated by multiple API index repos mirroring official docs):
| Endpoint (purpose) | Notes |
|---|---|
| Creator Search Open Collaboration Product | **The product-hunting endpoint.** Search all products on the TikTok Shop Affiliate Product Marketplace in open collaboration — filter by category, commission rate, keywords. Returns product info incl. commission. |
| Get Open Collaboration Product List By Product Ids | Detail lookup for product IDs found above |
| Search Creator Target Collaborations | Creator's targeted (invited) collaborations + products |
| Get / Add / Remove / Top Showcase Products | Manage the creator's product showcase programmatically (up to 2000 products) |
| Creator Generate General Link / Creator Generate Publisher Link | Generate affiliate promotion/share links for products |
| Creator Search Affiliate Trace Orders / Search Creator Affiliate Orders | Retrieve affiliate orders generated by the creator (order ID + product ID) — the commission reconciliation feed |
| Creator Sample Application APIs (search/detail/fulfillments) | Request/track free product samples |
| Upload Shoppable Video File / Post Shoppable Video / Get Shoppable Video Status / Precheck Video Content | **Post shoppable (product-tagged) videos directly via the Shop API** — an alternative to the Content Posting API for affiliate content |

**Affiliate Seller APIs** (authorized by a SELLER shop): open collaboration CRUD, seller-side creator search/marketplace, affiliate order lists, sample application review, promotion-link generation. Relevant only if the user also runs a seller shop.

**Affiliate Partner APIs** (TAP/CAP/MCN agencies): campaign creation, campaign product lists, CAP/TAP affiliate order search. Not needed for a single creator.

**Vietnam availability:** TikTok Shop operates in VN and the affiliate program exists there. The API surface is region-scoped (region codes include VN in shop APIs). ⚠️ **Not verified:** I could not find an official per-region availability matrix explicitly confirming every Affiliate Creator endpoint is enabled for VN — mark as *likely yes, verify in Partner Center sandbox*.

**Known API gaps (verified via third-party builders, consistent across sources):**
- No "Exposure Plus" / heat / GMV-ranking fields via API — product search returns category/commission/keyword filters only, not the marketplace's internal hotness signals. Paid third-party tools (FastMoss etc.) fill this.
- No official LIVE chat/gift/order realtime event API for creators — consistent with the repo's existing finding.

## 2. Content Posting API (developers.tiktok.com — open.tiktokapis.com/v2)

Separate from TikTok Shop; this is the TikTok for Developers API for posting short videos.

| Item | Detail |
|---|---|
| Two modes | **Direct Post** (`video.publish` scope): publishes immediately with caption, privacy, comment/duet/stitch settings — full hands-free automation. **Upload to Inbox/Drafts** (`video.upload` scope): video lands in creator's TikTok inbox; creator must finish manually in the mobile app (notification only visible in mobile app, not on web). |
| Upload methods | `FILE_UPLOAD` (chunked from server) or `PULL_FROM_URL` (TikTok fetches from public URL; domain must be verified in portal) |
| Auth | OAuth 2.0 + PKCE; access token 24h TTL, refresh token 365d TTL — must implement background refresh |
| Approval gates | (1) App review (~1–2 weeks: app description, privacy policy, use case). (2) **Direct Post audit** (~5–10 business days: submit demo video of upload flow). Until audited: max 5 users and `SELF_ONLY` (private) visibility only. Total ~3–4 weeks to full production. Request only scopes you use (TikTok rejects unused scopes). |
| Rate limits | **6 requests/min per user token** on publish endpoint; **~15 posts/day per creator account**, shared across ALL API clients using Direct Post |
| Mandatory UX | Must show creator nickname on upload page; user must pick privacy (no pre-selected default); must query `/creator_info/` for max duration and allowed privacy levels; comment/duet/stitch toggles required |
| VN availability | API is global; no region exclusion for VN found. *Yes (no contrary evidence found)* |

## 3. Rate limits, quotas, free vs paid

- **Both API families are FREE** — no usage fees, no paid tiers found. TikTok Shop developers also get zero listing fees on the TikTok Shop App Store. (Content Posting API explicitly documented as free by multiple integrators.)
- **Content Posting API:** 6 req/min per user token; ~15 posts/day/creator (hard numbers, well corroborated).
- **TikTok Shop Open API:** ⚠️ **Official per-endpoint rate limits NOT verified** — the docv2 pages are login-gated. Third-party integrators report ~1000 req/min general limits and standard 429 handling; error code `42901` (rate limit exceeded) exists in the official error taxonomy. Treat as *unverified; confirm in Partner Center docs after login*.
- No evidence of paid quota upgrades for either API.
