Kết nối TikTok (OAuth, làm một lần mỗi tài khoản)

Redirect URI phải khai báo y hệt trên developers.tiktok.com: http://127.0.0.1:8080publishers.html/tiktok/callback

  1. Bấm Kết nối TikTok ở dòng tài khoản → trang TikTok mở bằng phiên đã đăng nhập trên trình duyệt → chọn đúng tài khoản creator → Allow.
  2. TikTok tự chuyển về app này và lưu token — không cần copy gì. Mở app tại đúng địa chỉ trong Redirect URI (cùng cổng).

Token chỉ ghi vào file tiktok_token_<username>.json cạnh app, không hiển thị lên trang. Thiếu client key → set TIKTOK_CLIENT_KEY/TIKTOK_CLIENT_SECRET (xem docs/POSTPROD_RUNBOOK.md) rồi khởi động lại app.
