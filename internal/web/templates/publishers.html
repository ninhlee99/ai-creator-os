Lấy Client ID/Secret YouTube (Miễn phí, 1 lần duy nhất)

  1. Vào console.cloud.google.com → Tạo project mới.
  2. Vào API & Dịch vụ → Thư viện → Bật YouTube Data API v3.
  3. Vào Màn hình đồng ý OAuth → Loại Ngoài → Điền tên app → Lưu.
  4. Vào Thông tin xác thực → Tạo thông tin xác thực → Mã khách hàng OAuth → Loại Ứng dụng dành cho máy tính (Desktop) → Tạo.
  5. Copy Client ID và Client Secret → Dán vào Cài đặt · Hệ thống (YOUTUBE_CLIENT_ID, YOUTUBE_CLIENT_SECRET) → Quay lại đây bấm Nối YouTube.
