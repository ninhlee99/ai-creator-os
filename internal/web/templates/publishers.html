Kết nối Facebook · Instagram · Threads (Meta)

  1. Tạo app miễn phí tại developers.facebook.com → thêm sản phẩm Facebook Login, Instagram Graph API, Threads API.
  2. Lấy Page access token (quyền pages_manage_posts, instagram_content_publish) và Threads token.
  3. Dán vào Cài đặt · Hệ thống (mục “Mã & biến cấu hình”): FB_PAGE_ID, META_PAGE_TOKEN, IG_USER_ID, THREADS_USER_ID, THREADS_TOKEN.

Facebook: tải video thẳng từ máy, mặc định chưa công khai để bạn duyệt. Instagram Reels: tải thẳng từ máy; API không có nháp nên chỉ đăng công khai khi bật IG_AUTO_PUBLISH=1. Threads: API chỉ nhận video qua link công khai, nên app đăng bài chữ kèm link sản phẩm/video để kéo traffic chéo.

Token chỉ ghi vào file tiktok_token_<username>.json cạnh app, không hiển thị lên trang. Thiếu client key: tạo app tại developers.tiktok.com, rồi nhập Client Key/Secret ở Cài đặt · Hệ thống (mục "Mã & biến cấu hình").

Kết nối YouTube (làm một lần mỗi tài khoản)

  1. Bấm Nối YouTube ở dòng tài khoản → trang Google mở bằng phiên đã đăng nhập trên trình duyệt → chọn đúng kênh YouTube → Cho phép.
  2. Google tự chuyển về app này và lưu token — không cần copy gì. Mở app tại {{.AppBase}} (địa chỉ máy local, đúng cổng đang chạy).

Chưa có Client ID/Secret? Bấm Nối YouTube để xem hướng dẫn tạo (miễn phí) rồi dán vào Cài đặt · Hệ thống (mục “Mã & biến cấu hình”). Token chỉ ghi vào file youtube_token_<username>.json cạnh app, không hiển thị lên trang.

Video đăng lên ở chế độ riêng tư trước — bạn xem lại rồi mới cho công khai (đổi ở trang Kể chuyện → mục “Mặc định & tự động”).

Lấy Client ID/Secret YouTube (miễn phí, làm một lần)

  1. Vào console.cloud.google.com → tạo project mới (hoặc chọn project cũ).
  2. “API & Dịch vụ” → “Thư viện” → tìm YouTube Data API v3 → Bật.
  3. “Màn hình đồng ý OAuth” → loại Ngoài → điền tên app → Lưu.
  4. “Thông tin xác thực” → “Tạo thông tin xác thực” → Mã khách hàng OAuth → loại ứng dụng Ứng dụng dành cho máy tính → Tạo.
  5. Copy Client ID và Client Secret → dán vào Cài đặt · Hệ thống → “Mã & biến cấu hình” (YOUTUBE_CLIENT_ID, YOUTUBE_CLIENT_SECRET) → quay lại đây bấm Nối YouTube.

Lưu ý: app đang ở chế độ Thử nghiệm → Google thu hồi quyền sau 7 ngày. Để dùng lâu dài: vào “Màn hình đồng ý OAuth” → Xuất bản ứng dụng.
